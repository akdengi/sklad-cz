# 12. Вывод товара из оборота

## Что это такое

Вывод из оборота — это процесс снятия товара с учёта в системе Честный Знак. Выполняется после продажи товара конечному покупателю.

## Когда подавать отчёт

- После продажи товара (через кассу или маркетплейс)
- В течение **3 рабочих дней** с момента продажи
- На странице «Сводка» отображаются дедлайны

## Порядок действий

### Шаг 1: Оформите продажу в приложении

1. Продайте товар через вкладку **«Продажа»**
2. Убедитесь, что статус изменился на **«Продан»**
3. Заполнены все данные: номер заказа, цена, адрес

### Шаг 2: Подайте отчёт через ЛК ЧЗ

**ПОДХОДЯЩИЙ ВАРИАНТ для дистанционной продажи (маркетплейсы):**

1. Перейдите в вкладку **«Вывод из оборота»**
2. Отфильтруйте товары по статусу **«Не начато»** (это проданные товары)
3. Отметьте нужные единицы чекбоксами
4. Нажмите кнопку **«Вывод из оборота (API)»**
5. В модальном окне проверьте:
   - Корректный КМ код (KI)
   - Цена продажи
   - Номер документа (номер заказа)
6. Подтвердите отправку

**АЛЬТЕРНАТИВНЫЙ ВАРИАНТ — ручная подача в ЛК ЧЗ:**

1. Войдите в личный кабинет Честный Знак: https://markirovka.crpt.ru
2. Перейдите в раздел **«Отчёты»** → **«Отчёт о выводе из оборота»**
3. Создайте новый отчёт
4. Заполните:
   - **ИНН** организации
   - **Код продукции** (KИ)
   - **Причина вывода**: «Дистанционная продажа»
   - **Дата вывода**
   - **Документ-основание**: номер заказа
5. Подпишите отчёт ЭЦП
6. Отправьте

### Шаг 3: Обновите статус в приложении

1. Через 1-2 дня перейдите в **«Настройка»**
2. Нажмите **«Обновить статусы всех товаров»**
3. Статус товара должен измениться на **RETIRED** (Выбыл) или **WITHDRAWN** (Выведен)
4. Статус отчёта автоматически станет **«Подтверждено ЧЗ»**

## Экспорт данных для отчёта

Для удобства preparation и подачи отчёта:

1. Перейдите в **«Настройка»**
2. Нажмите **«Экспорт вывода из оборота CSV»**
3. В файле будут:
   - Полный КМ код
   - Код для отчёта (KI — только GTIN + серийный номер без криптохвоста)
   - Цена продажи
   - Номер заказа

## Отслеживание отчётов через API

Во вкладке **«Вывод из оборота»** отображаются:
- Единицы, требующие отчёта (статус **«Не начато»**)
- Отправленные отчёты (статус **«Отправлено в ЧЗ»**)
- Подтверждённые отчёты (статус **«Подтверждено ЧЗ»**)

### Статусы отчётности

| Статус | Описание |
|--------|----------|
| Не начато | Товар продан, отчёт не подан |
| Отправлено в ЧЗ | Отчёт отправлен через API, ожидает обработки |
| Подтверждено ЧЗ | Отчёт принят и подтверждён системой Честный Знак |

### Автоподтверждение

При проверке статуса отчёта (через кнопку «Обновить статусы всех товаров») отчёт автоматически подтверждается если статус в ЧЗ = **RETIRED** / **WITHDRAWN** / **WRITTEN_OFF**.

### Колонки таблицы

| Колонка | Описание |
|---------|----------|
| **Статус отчёта** | Не начато / Отправлено в ЧЗ / Подтверждено ЧЗ |
| **Статус в ЧЗ** | Текущий статус в системе Честный Знак |

### Автоматическая проверка

При нажатии кнопки **«Подтвердить и отправить»**:
1. Выводится модальное окно с предпросмотром данных
2. Статус меняется на **«Отправлено в ЧЗ»**
3. Документ отправляется в API Честный Знак

После подтверждения отчёта в ЛК ЧЗ статус автоматически обновится на **«Подтверждено ЧЗ»** при следующей проверке.

При открытии карточки единицы статус в выпадающем списке **«Статус»** синхронизируется со статусом ЧЗ:

- Если товар **продан** (переключатель «Продан» включён), дропдаун показывает статус из ЧЗ (например, «В обороте»), а не пустоту
- Переключатель «Продан» — единственный способ пометить товар как проданный (значение `status=4` не отображается в списке)
- При сохранении: если «Продан» включён → статус = 4, иначе — берётся значение из дропдауна

## Массовая проверка отчётов

1. Отметьте нужные товары **чекбоксами** во вкладке «Вывод из оборота»
2. Нажмите **«Проверить статус в ЧЗ (N)»**
3. Система проверит каждый товар и обновит статусы

## Возврат товара

Если товар был возвращён покупателем, нажмите кнопку **«Вернуть в оборот»** напротив товара со статусом «Подтверждено ЧЗ». Подробнее: [Возврат товара](13-vozvrat.md).

## Типы выбытия

| Тип | Описание |
|-----|----------|
| **Перед отгрузкой** | Товар отгружается покупателю |
| **При возврате товара** | Товар возвращён от покупателя |

## Причины выбытия

| Причина | Когда использовать |
|---------|-------------------|
| Дистанционная продажа | Продажа через интернет-магазин / маркетплейс |
| Возврат при дистанционном способе продажи | Возврат интернет-заказа |
| Прочее | Другие случаи |

## Вид первичного документа

При заполнении данных для вывода из оборота указывается вид первичного документа. Порядок вариантов в выпадающем списке:

1. **Прочее** (по умолчанию)
2. **УПД**
3. Товарная накладная
4. Акт приёма-передачи
5. Кассовый чек

При оформлении продажи через вкладку **«Продажа»** вид документа выбирается отдельным полем **«Вид док-та»** (по умолчанию — «Прочее») и автоматически подставляется во все позиции заказа.

## Важно

- Отчёт нужно подавать в течение 3 рабочих дней
- Без подачи отчёта товар останется в статусе «В обороте»
- Статус RETIRED в ЧЗ = товар выбыл, дальнейшие операции невозможны
