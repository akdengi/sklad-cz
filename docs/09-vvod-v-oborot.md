# 9. Ввод товара в оборот

## Что это такое

Ввод в оборот — это процесс, при котором товар с нанесённым кодом маркировки становится доступен для продажи. До ввода в оборот товар нельзя продавать.

## Когда нужен ввод в оборот

- После нанесения кодов маркировки на товар
- После подачи отчёта о нанесении
- Статус КМ должен быть **APPLIED** (Нанесён)

## Ввод в оборот через приложение

### Шаг 1: Подготовка

1. Перейдите во вкладку **«Остатки»**
2. Убедитесь, что единицы имеют статус **«Нанесён»**
3. Укажите в карточке SKU:
   - **ТН ВЭД** — код товара
   - **ИНН фактического производителя** — по умолчанию ваш ИНН из настроек
   - **Разрешительная документация** — тип, номер и дата документа

### Шаг 2: Выбор метода ввода в оборот

Выделите нужные единицы (все должны быть одного SKU и статуса «Нанесён») и нажмите **«Ввод в оборот»**.

Доступно 4 метода:

| Метод | Когда использовать | Тип документа ЧЗ |
|-------|-------------------|------------------|
| **Производство в РФ** | Вы производитель товара | LP_INTRODUCE_GOODS |
| **Остатки** | Товар был получен от поставщика, вы собственник | LP_INTRODUCE_OST |
| **Контрактное производство** | Товар произведён на заказ по вашему ТЗ | LK_CONTRACT_COMMISSIONING |
| **Импорт с ФТС** | Товар ввезён из-за пределов ЕАЭС | LP_FTS_INTRODUCE |

### Производство в РФ

- **ИНН** — берётся из настроек (вы и производитель, и собственник)
- **Дата производства** — обязательна
- **Разрешительная документация** — подтягивается из карточки SKU

### Остатки

- **ИНН собственника** — берётся из настроек
- **Страна производства** — код ОКСМ (643 = Россия)
- **Декларация на товары** — обязательна только для товаров **не из России** (номер и дата)
- Для российских товаров декларация не нужна, используются сертификаты из карточки SKU

### Контрактное производство

- **ИНН собственника** — берётся из настроек (только чтение)
- **ИНН фактического производителя** — из карточки SKU (можно изменить)
- **Дата производства** — обязательна

### Импорт с ФТС

- **Регистрационный номер ДТ** — например `50999020/010721/0002040`
- **Дата регистрации ДТ** — обязательна
- **Дата производства** — необязательна

## Статус в приложении

| Статус ЧЗ | Статус в приложении | Действие |
|-----------|---------------------|----------|
| EMITTED | Эмитирован | Нанести код на товар |
| APPLIED | Нанесён | Ввести в оборот |
| INTRODUCED | В обороте | Товар готов к продаже |

## Важно

- Ввод в оборот доступен **только** для единиц со статусом «Нанесён»
- Все единицы должны принадлежать **одному SKU**
- Без ввода в оборот товар нельзя продать
- Проверяйте статусы регулярно через функцию массовой проверки
